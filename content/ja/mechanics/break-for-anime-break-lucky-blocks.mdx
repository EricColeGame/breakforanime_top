## コアループの仕組み：強奪・確保システム

基本的なゲームプレイのループは、危険な採掘ゾーンに潜入し、謎のノードを破壊して、ドロップしたエンティティを自身のセーフエリア（プロット）まで無事に持ち帰るという流れです。コンセプト自体はシンプルに見えますが、成功率を左右するいくつかの重要なメカニクスが存在します。

ブロックを攻撃すると、装備しているツルハシのティア、現在の攻撃力倍率、有効な一時的バフに基づいてダメージが計算されます。ブロックの耐久値がゼロになると粉砕され、基本的なミームキャラクターから高倍率のアニメスピリットまで、固有のエンティティドロップが出現します。

同様のブロック破壊モードにおけるプレイヤーの検証によると、中央エリアに長く留まるほど、危険に晒されるリスクは加速度的に上昇します。

```
危険ゾーンに侵入 ➔ 最適なブロックを特定 ➔ 耐久値を削り破壊 ➔ エンティティを回収 ➔ 巡回を回避 ➔ プロットへ持ち帰り確保
```

### リスクとリワードのパラメーター

安定して生き残るためには、危険との遭遇や回収に関わる基本ルールを理解しておく必要があります。

*   **索敵（ヘイト）範囲:** 巡回エネミーは視界コーンを持っていますが、ブロックを叩く音による警戒トリガーによって、その範囲が一時的に拡大します。
*   **重量ペナルティ:** 上位ティアのドロップを運搬している間は基本ダッシュ速度が低下し、安全な脱出が著しく難しくなります。
*   **拠点プロットへの配置:** ドロップしたエンティティは、指定された自身のプロットグリッド上に物理的に配置するまで、キャッシュやパッシブボーナスを生成しません。

| ゲームフェーズ | 主な目的 | 危険度 | 最適なプレイヤーアクション |
| :--- | :--- | :--- | :--- |
| **潜入** | 上位ティアのブロック群を索敵 | 低 | 遮蔽物の合間をしゃがみ・ダッシュで移動 |
| **発掘** | ブロックのHPを迅速に削る | 中〜高 | 攻撃のクールダウンキャンセルを活用 |
| **戦利品回収** | 出現したエンティティを拾う | 高 | 拾う前に巡回ルートを再確認 |
| **脱出** | 拠点プロットの境界線へ直行 | 致命的 | ジグザグに走ってNPCの視線を切る |
| **配置** | エンティティを拠点に固定 | 安全 | ティック収益が最大化するようグリッドを整理 |

## ラッキーブロックのティア、耐久値、ドロップ配分

すべてのブロックから同じリターンが得られるわけではありません。下位ティアのブロックばかり狙えば危険は最小限に抑えられますが、キャッシュの蓄積速度は停滞します。逆に、採掘装備を強化しないままレジェンダリーやミシカルティアに手を出すと、長時間無防備に立ち止まることになり、巡回ボスに瞬殺される原因となります。

コミュニティの検証報告によると、ブロックは一定周期の全体リフレッシュ、またはエリア内のクラスタが全滅したタイミングでリスポーンします。中〜高ティアを優先する効率的なルートを設計することで、無謀な特攻を避行いつつ、高ステータスのドロップを安定して集めることが可能です。

### ソロプレイヤー向けのステータス優先順位

スキルツリーやショップで強化を進める際、移動速度、純粋な採掘力、バックパック容量のどれを優先すべきか悩むプレイヤーは少なくありません。サバイバル計算に基づく優先度は以下の通りです。

1. **採掘力（最優先）:** 無防備な時間を減らすことが最大の防御策です。2撃でブロックを破壊できれば、NPCに感知されるリスクを最小限に抑えられます。
2. **移動速度（準優先）:** 重いドロップを抱えて拠点へ全力疾走する際、生還率を大きく左右します。
3. **所持容量（状況依存）:** 脅威から確実に逃げ切れる走力を確保して初めて役立ちます。逃走速度が足りない状態で複数のエンティティを抱えるのは極めて危険です。

## 回避戦略：巡回AIの挙動と視線の切り方

巡回する敵（Sammyやマップ固有の監視者など）は、決定論的なステートマシン（巡回、警戒、追跡、リセット）に基づいて行動しています。これら4つの行動フェーズを把握することで、経路探索の弱点を突き、一度も捕まることなく回収を完了させることができます。

```
巡回（緑） ➔ 警戒（黄：物音を感知） ➔ 追跡（赤：直接追跡） ➔ リセット（青：巡回ルートへ復帰）
```

### 敵AIの行動パターンの解析

採掘などのアクションを起こすと、付近の巡回エネミーは「警戒」状態に入ります。警戒中にエネミーの視界内に留まり続けると、即座にダッシュを伴う「追跡」へ移行します。多くのボスは徐々に加速する仕様を持っているため、直線的に走って引き離すのではなく、障害物を利用して素早く視線を切る（Line of Sightを遮る）ことが逃走の鍵です。

| AIステート | 移行トリガー | 視覚的な兆候 | 推奨される回避マニューバ |
| :--- | :--- | :--- | :--- |
| **巡回** | デフォルトの待機・移動 | 低速歩行、通常時の視線 | 視界コーンの外側（背後）を自由に移動 |
| **警戒** | 付近でのブロック破壊音 | 立ち止まり、音の発生源に顔を向ける | 即座に採掘を止め、低めの遮蔽物に身を隠す |
| **追跡** | 直接の視認 | 咆哮 / 高速突進 | 角を鋭角（90度）に曲がり障害物を挟む |
| **リセット** | ターゲットを4秒以上見失う | 低速で巡回ルートへ戻る | 別の方角や側面からエリアに再侵入 |

### 回避の重要テクニック
*   **コーナーカッティング:** 敵の経路探索はプレイヤーの現在座標を追跡して計算されます。角を鋭角に曲がるとAIは再計算を強いられ、突進速度を数秒間削ることができます。
*   **段差の活用:** 小さなスロープや段差から飛び降りることで、基本的な巡回トラッキングを撹乱し、拠点へ走り抜ける隙を作れます。
*   **囮ドロップ（サクリファイス）:** 追い詰められた場合、低ティアのコモンアイテムをその場に捨ててください。一部のAIルーチンは落下した戦利品に反応して一瞬立ち止まるため、脱出の貴重な猶予が得られます。

## 上級者向け周回ルートとタイミング

他プレイヤーに差をつけるためには、ノープランで中央へ突入するのは避けましょう。最も効率の良いプレイヤーは、サーバーのリスポーンタイマーに合わせた決まった巡回ルートを構築しています。

### 低リスク・外周スイープロート
*   スタンダードブロックやアンコモンブロックが湧く外周エリアを周回する。
*   中央の中庭には一切立ち入らない。
*   Rusty PickaxeやReinforced Steelを使用している序盤プレイヤーに最適。
*   ボスのヘイトを買うことなく、安定して手堅いキャッシュを稼げる。

### 中央ダイブ・スナイプルート
*   巡回エネミーがアリーナの最も遠い角へ移動するのを待つ。
*   レアやミシカルブロックが存在する中央の高台へ一直線にダッシュする。
*   高攻撃力のツルハシで素早く連続攻撃を叩き込む。
*   ドロップを拾ったら、境界線に向けて最短の直線ルートで一気に離脱する。

これらの移動ルートを日々の立ち回りに組み込むことで、リスクの高いギャンブルを、計算された安定した成長サイクルへと昇華させることができます。

## よくある質問（FAQ）

### ブロックドロップを運搬中にNPCに捕まったらどうなりますか？
プロットの境界線を越える前に監視NPCに捕まると、その回の遠征で拾った未バンクのエンティティをすべてその場に落とし、自身の拠点テリトリーでリスポーンします。ただし、購入済みのツールやキャラクターの永続アップグレードが失われることはありません。

### 最もレアなブロックのリスポーン頻度はどのくらいですか？
低ティアのブロックは15〜30秒ごとにリスポーンしますが、コミュニティの報告によると、ミシカルやアニメレリックのブロックは3〜5分のタイマーで出現するか、下位ティアのブロックがエリア内から一掃された直後に即時湧きする仕様となっています。

### グループでプレイすると攻略は楽になりますか？
はい。グループで連携すれば、1人が囮役となって貴重な中央クラスタから巡回エネミーのヘイトを引き付け、その間にチームメイトが妨害を受けることなく高耐久ブロックを安全に破壊するといった戦術が可能になります。

### ツルハシのアップグレードを早めるアクティブコードはありますか？
コードの配布状況はバージョンのアップデートによって異なります。開発者からコードが公開される場合、一時的な移動速度アップのエリクサー、無料の初期資金、限定のスターターツルハシなどが配布されるのが一般的です。最新情報については、公式コミュニティのアナウンス掲示板を定期的に確認してください。
