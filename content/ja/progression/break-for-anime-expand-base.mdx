## 実践ステップ解説：空中ラダーリセットの連携手順

空中ラダーは、アリーナにおいて最も効果的なテクニカルループの一つです。空中で相手のヒットスタンをリセットし、基本的なトレードから極限までダメージを引き出すことができます。

```
ステップ1：地上始動 ➔ 安定したM1を3発当てる
           │
ステップ2：スペース + M1 ➔ 空中へ打ち上げ
           │
ステップ3：ニュートラルポーズ ➔ 0.5秒待機（またはコンボエクステンダー使用）
           │
ステップ4：スペース長押し + M1連撃 ➔ 空中ラダーヒット
           │
ステップ5：スペースを離して最終M1 ➔ 強力な地面叩きつけ（1秒スタン）
```

1.  **ニュートラルでのヒット確認：** 地上でM1攻撃を3発確実にヒットさせます。4段目まで出してしまうとノックバックスケールが増加して追撃が難しくなるため、3段目で止めます。
2.  **空中への打ち上げ：** 3発目の攻撃入力時にスペースキーを長押しし、自身とターゲットを同時に空中へ打ち上げます。
3.  **0.5秒の静止ポーズ：** 空中に移行したら、約0.5秒間入力を一時停止します。あるいは、この隙を誘導性能のあるコンボエクステンダーでキャンセルして繋ぎます。
4.  **ラダー連撃の入力：** ジャンプキーを長押ししたまま、空中でM1連撃を続行します。これにより敵を空中に浮かせ続け、ヒットスタン状態に拘束します。
5.  **叩きつけフィニッシュ：** 空中最終段のM1を押す直前に、スペースキーを離します。これにより空中ノックバックが下方向への叩きつけへと変化し、敵を地面に激突させて丸々1秒間のスタン状態に追い込みます。
6.  **地上での追撃：** この1秒間のダウンスタンを利用して、ガード不能の必殺技を重ねる、クールダウンを回復する、あるいは相手の起き上がりローリングに合わせて**break for anime expand base**の追撃を仕掛ける有利なポジションを確保します。

この中核となる実戦コンボをマスターすることで、一度の隙から確実に大ダメージをもぎ取り、自信を持ってアリーナのランクマッチを勝ち上がることができます。

## よくある質問（FAQ）

### Anime Expand Baseにおける「ブレイク（break）」とは何を意味しますか？
**break for anime expand base**のセットアップとは、ガードブレイク技やキャンセル動作を駆使して相手のシールドをこじ開け、覚醒モードを使用する前のベース（通常）形態のコンボを最大限のダメージ連携へと延伸・展開させる技術を指します。

### 相手がシールドに籠もって徹底的にタートル戦法を取る場合はどうすべきですか？
ガードを固めている相手に対して、地上の標準的な5段M1を出し切ってはいけません。最終段を外すと自身が1秒間のスタンに陥り危険です。代わりに、青雉（クザン）の暴喰雉のような安全な飛び道具系ガードブレイク技や、相手のガードフレームを安全に貫通・崩せる多段ヒットスキルを使用してください。

### 「怪力（Immense Strength）」などのプレイヤーパッシブはコンボ火力にどう影響しますか？
怪力パッシブを持つキャラクターは、M1の1打あたりの基礎ダメージが4.1を超えます。この攻撃力スケールのおかげで、長時間のクールダウンを伴う大技を消費することなく、標準的なラダーリセットを絡めるだけで凄まじい瞬間火力を叩き出すことが可能です。

### 覚醒アルティメット技はすべて相手を一撃で倒せますか？
いいえ、すべてではありません。真の一撃必殺技は115以上のダメージを与えてベースHPのキャラクターを即死させますが、引き換えに自身の覚醒モードが即座に終了したり、体力が1まで削られたりします。その他のアルティメットは覚醒ゲージを数本消費するだけにとどまり、変身状態を維持したまま継続して攻め立てることが可能です。
